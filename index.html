E-commerce completo para una marca de ropa streetwear de Manizales: catálogo con variantes (talla, color, stock y SKU), carrito persistente, checkout con pago contra entrega, cuentas de cliente y un panel administrativo para gestionar el negocio.

Pedidos sin duplicados

Cada checkout genera una requestKey única y el backend valida el stock dentro de una transacción: un doble clic o una recarga no crea dos pedidos.

Seguridad

Autenticación JWT con roles (ADMIN / CUSTOMER), política estricta de contraseñas, validación con Zod, Helmet y rate limiting.

Panel administrativo

Métricas de ventas, CRUD de productos con variantes y seguimiento de pedidos: pendiente → pagado → enviado → entregado.

Correos y newsletter

Confirmación de pedido y envío masivo de newsletter con la API de Brevo, por lotes y con límite de velocidad.
